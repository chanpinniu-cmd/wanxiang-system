# 灰度用户管理

线上开通万象使用权限的灰度名单。导入班主任工号后即时开通，并在看板上看到当前有多少人在使用。

**先看这几件事**

- 只校验工号。向工作台查询：工号不存在，或员工已离职，这一行失败。教授学科、归属组织不校验。
- 名单里已有的工号再次导入：更新学科和组织，状态改为已启用，开通时间保持第一次开通的时间。
- 移除后这个人离开名单，看板人数随之减少。之后再导入，开通时间改记为这一次的导入时间。

## 看板

三张数字都按全部名单计算。筛选只缩小下面的表格，不改变看板。

| 页面上的名称 | 怎么算 |
| --- | --- |
| 配置总人数 | 已经配置的班主任人数相加 |
| 已启用人数 | 状态为已启用（已开启）的人数相加，已禁用不计入 |
| 已禁用人数 | 状态为已禁用的人数相加 |

移除一人，配置总人数减 1。移除前是已启用，已启用人数减 1；移除前是已禁用，已禁用人数减 1。

## 页面提示

> 导入以班主任工号为唯一标识。工号需在工作台存在且为在职；学科、组织不校验。已在名单中的工号再次导入时，更新教授学科和归属组织，状态变为已启用，开通时间仍取首次开通时间。从名单移除后再次导入，开通时间按再次导入的时间记录。

## 筛选

五个条件都是单值，一次只选一个状态：

- 班主任 ID（工号）
- 班主任姓名，按姓名包含匹配；姓名为空的记录不会被命中
- 教授学科
- 归属组织
- 启用状态：全部状态、已启用、已禁用

## 名单

一行一位班主任。班主任姓名来自导入文件，填了就原样显示，没填显示 —，不校验是否填写。学科或组织为空时同样显示 —。

列：班主任 ID（工号）、班主任姓名、教授学科、归属组织、开通时间、状态、操作。

操作有「禁用 / 启用」和「移除」。禁用只把状态改为已禁用，开通时间不变。移除需确认，确认后该班主任从列表消失。

## 导入

标题右侧同一行放两个按钮，从左到右是：

- **下载空白模板**：表头为 `班主任ID,班主任姓名,教授学科,归属组织`。工号必填，姓名、学科、组织都可以不填。工号列要用文本，保留前导零。
- **导入工号**：上传这份 UTF-8 CSV。文件不超过 5 MB。

上传后按工号逐行判断：

| 情况 | 结果 |
| --- | --- |
| 工作台查不到该工号 | 失败原因：工号不存在 |
| 工号存在，但是已离职 | 失败原因：员工已离职 |
| 工号为空、列数不对 | 失败原因写入对应说明，这一行不导入 |
| 表头不对、不是 CSV、超过 5 MB、编码无法识别 | 整份文件不导入 |

只要文件里有「工号不存在」或「员工已离职」，导入结果处提示：

**当前导入文件中存在工号不存在或已离职请下载失败内容后再重新导入。**

点「下载失败内容」得到 CSV，在原表头后多一列「失败原因」。通过校验的工号仍可确认导入。

确认导入时：

- **新工号**，或移除之后再次出现的工号：状态为已启用，开通时间取确认当时的北京时间。
- **名单中还在的工号**：更新班主任姓名、教授学科、归属组织，状态改为已启用。即使原来是已禁用，也会重新变为已启用。开通时间不改，仍显示首次开通时间。
